# Outputs Guide

This guide shows where simulator and ML artifacts are written and how to compare the surrogate trainers.

## Run bundle (single simulation)

- `fields.npz`: core arrays (`C_snap`, `D`, `k`, `patch_mask`, `t`, `J`)
- `meta.json`: grid and boundary settings
- `metrics.json`: scalar summaries from the simulator

Optional when generated by validation scripts:
- `diagnostics.json`
- `bc.json`

## Dataset artifacts

- `outputs/sim/<dataset_name>/dataset/run_###/`: per-run bundles used by ML
- `data/processed/`: assembled split arrays and `index.json`
- `data/processed/ml/`: ML export arrays (`X`, `y_scalar`, `J`, `t`) and `meta.json`

Notes:
- Training scripts now operate on logical splits: `train`, `val`, `test`.
- Split keys in `data/processed/ml/meta.json` must be `train`, `val`, and `test`.

## QC outputs

- `outputs/qc/<name>/qc_report.json`: split counts, scalar coverage, and summary checks
- `outputs/qc/<name>/qc_distributions.png`: feature/target distribution figure
- `outputs/qc/run_integrity_report.json`: run-level file and shape checks
- `outputs/qc/fix_runs_report.json`: regeneration summary when using `fix_runs`

## Blackbox outputs

Run folder: `outputs/ml/<run_name>/`

- Metrics: `metrics_val.json`, `metrics_test.json`
- Predictions: `pred_val.npz`, `pred_test.npz`
- Runtime and summary: `runtime.json`, `summary.json`
- Physics diagnostics:
  - `diagnostics/physics/physics_diag_val.csv`
  - `diagnostics/physics/physics_diag_test.csv`
  - `diagnostics/physics/physics_diag_val_summary.json`
  - `diagnostics/physics/physics_diag_test_summary.json`
  - `diagnostics/physics/physics_diag_val_worst.json`
  - `diagnostics/physics/physics_diag_test_worst.json`
- Plots:
  - `plots/test/curve_examples.png`
  - `plots/test/curve_error_over_time.png`
  - `plots/test/scalar_parity.png`
  - `plots/test/scalar_residuals.png`

## PINN outputs (`train_pinn.py`)

Run folder: `outputs/ml/<run_name>/`

- Metrics: `metrics_val.json`, `metrics_test.json`
- Predictions: `pred_val.npz`, `pred_test.npz`
- History/summary: `history.json`, `summary.json`
- Physics diagnostics:
  - `diagnostics/physics/physics_diag_val.csv`
  - `diagnostics/physics/physics_diag_test.csv`
  - `diagnostics/physics/physics_diag_val_summary.json`
  - `diagnostics/physics/physics_diag_test_summary.json`
  - `diagnostics/physics/physics_diag_val_worst.json`
  - `diagnostics/physics/physics_diag_test_worst.json`
- Plots:
